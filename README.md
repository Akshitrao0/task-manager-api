# Task Manager API 🚀

A simple REST API for managing tasks built with Node.js and Express.

## Quick Start

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/task-manager-api.git
cd task-manager-api

# Install dependencies
npm install

# Setup environment
cp .env.example .env

# Start development server
npm run dev
